# NEXUS Standard Library

- `std.io`: `read_line`, `read_i64`, `read_f64`
- `std.fs`: `fs_read`, `fs_write`, `fs_exists`
- `std.net`: `http_get_text`
- `std.json`: `json_field`
- `std.db`: `db_open`, `db_exec`, `db_close`
- `std.memory`: `memory_alloc`, `memory_free`
- `std.crypto`: `hash_sha256`
- `std.math`: scalar gameplay helpers (`math_clamp`, `math_lerp`, `math_approach`, `math_sign`)
- `std.engine2d`: convenience wrappers for the existing 2D runtime
- `std.tilemap`: tilemap storage, drawing and axis-separated collision helpers
