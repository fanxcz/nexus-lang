# NEXUS Standard Library

- `std.io`: `read_line`, `read_i64`, `read_f64`
- `std.fs`: `fs_read`, `fs_write`, `fs_exists`
- `std.net`: `http_get_text`
- `std.json`: `json_field`
- `std.db`: `db_open`, `db_exec`, `db_close`
- `std.memory`: `memory_alloc`, `memory_free`
- `std.crypto`: `hash_sha256`
- `std.math`: scalar math helpers and floor rounding
- `std.engine2d`: core 2D window, frame, input and primitive drawing
- `std.tilemap`: bounded grid data and cell access
- `std.collision2d`: AABB/circle tests and tilemap movement resolution
- `std.tilemap_render`: viewport-aware colored tile drawing
- `std.animation2d`: time-based sprite animation frame calculation
- `std.sprite2d`: texture and sprite-sheet rendering
- `std.camera2d`: runtime camera wrappers
- `std.audio2d`: optional runtime sound loading/playback
