Getting started / 01

From zero to
first executable.

Install the compiler, verify the local toolchain and compile a small NEXUS program. The Windows bundle is the simplest prebuilt route.

On this pageInstallVerifyFirst programCreate a projectNext steps
Step 01

Install NEXUS

For Windows 10/11 x64, use the self-contained installer or portable bundle. The installer is per-user and does not require administrator rights. Linux and macOS binaries are published through GitHub Releases when available.

Open downloads ↗

Windows bundle: keep the compiler, toolchain, runtime, standard-library and project-template folders together. The installer can add the compiler to your user PATH.
Step 02

Check your environment

Open PowerShell or a terminal and run:

nexus --version
nexus doctor

Use nexus doctor to diagnose the compiler/runtime setup. On Windows, reopen the terminal after adding NEXUS to PATH.

Step 03

Write a first program

Create a file named hello.nx:

fn main() {
    print("Hello from NEXUS!")
}

Check and run it directly from the terminal:

nexus check hello.nx
nexus run hello.nx
Step 04

Create a project

The project command copies a starter scaffold into a new directory. Start with a CLI utility:

nexus new HelloNexus --template cli
cd HelloNexus
nexus check
nexus build
nexus run

For a native windowed program, replace cli with app. Other checked-in templates include game, 3d, paint, server and library.
