Windows troubleshooting

Another NEXUS version is launching?

Windows can have multiple NEXUS copies on PATH. Check which launcher is being selected and test the per-user installation directly before changing or removing anything.

Get-Command nexus -All | Format-Table CommandType, Source, Definition
where.exe nexus
& "$env:LOCALAPPDATA\Programs\NEXUS\nexus.cmd" --version

The first two commands list matching launchers. The last command bypasses PATH and checks the normal per-user installation. Keep your projects and source files when cleaning up an older compiler copy.
