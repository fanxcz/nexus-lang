01 / The idea

One language.
Two compilation paths.

The frontend checks your program once. The built-in x86-64 backend emits machine code for its documented subset; the LLVM path covers a broader set of language features.

Path A / DirectPE32+ · ELF64

Built-in native backend

Direct x86-64 code generation for supported Windows and Linux programs. No separately installed compiler is needed for programs inside this subset.

SMALL & DIRECTRead the limits ↗
Path B / LLVMBroader coverage

LLVM / Clang path

LLVM IR is used for wider type and runtime support. A compatible Clang-style toolchain is required, and target availability depends on the active toolchain.

real desktop work.

NEXUS is aimed at useful native software, not at promising a finished game engine or an all-purpose desktop framework. Here is what exists in the repository today.
