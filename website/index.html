The NEXUS Programming Language

NEXUS is a statically checked language for native applications, developer tools and game prototypes. Its compiler is written in C++20 and includes a built-in x86-64 backend alongside an LLVM compilation path.

The language

Designed for native software

The frontend checks the program once. Choose the code-generation path according to the features used by your program.

Built-in backendWindows · Linux

Native x86-64

Direct machine-code generation for a documented subset of the language. Supported programs do not need a separately installed compiler.

PE32+ · ELF64Backend details →
Additional backendLLVM / Clang

LLVM compilation

Provides broader language feature coverage through LLVM IR and a compatible Clang-style toolchain.
