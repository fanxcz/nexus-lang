NEXUS Studio is a separately packaged Electron desktop workspace for opening projects, editing a source file and running the NEXUS compiler from an integrated terminal.

Workspace / 02

Keep the compiler in control

Studio does not bundle the NEXUS compiler. Install it separately; the app detects common locations and can remember a selected compiler path. The official Windows distribution uses its helper script to configure the bundled toolchain and runtime DLLs.

Open a project, choose a .nx file, edit it, then use Build or Run. The command palette exposes common workspace actions and can be opened with Ctrl/Cmd+Shift+P.

Distribution / 03

Cross-platform builds

The desktop build workflow packages Windows, Linux and macOS on their native runners. The build workflow uploads temporary CI artifacts; the release workflow can prepare a draft GitHub release with SHA-256 sidecars for maintainer review.

Prepare draft release ↗

There is not currently a permanent public Studio release attached to the repository. Do not mistake temporary Actions artifacts for published downloads.

Current limitations

Preview, not a full IDE yet

Studio currently shows one active editor tab at a time. It does not include a debugger, Git client, integrated LSP diagnostics panel or multi-file refactoring UI. The terminal runs commands with the current operating-system user's permissions. File access is restricted to the selected project folder, and files larger than 2 MB are not opened in the editor.
