Workflow / 02

From source to running program

Open a project folder with Ctrl/Cmd+O. Use the explorer filter to locate source files, open multiple tabs and edit them independently. Unsaved tabs are marked; save the current file with Ctrl/Cmd+S or save all open tabs from the command palette.

Choose the NEXUS compiler from the toolbar when automatic discovery cannot find it. Press F7 to build or F5 to build and run. Compiler errors and warnings with file and line information appear in Problems; the terminal keeps the complete process output.

Current scope

What is included—and what is not

Studio 3.0.0 includes a multi-tab code editor, project explorer, filename filter, compiler Build/Run actions, process terminal, command palette and a Problems list for diagnostics that include source locations. The terminal executes local commands with the current operating-system user's permissions; run only commands you trust.

A graphical debugger, Git client, full language-server protocol client, symbol index and multi-file refactoring engine are not included in this release. For richer language diagnostics, completion and navigation, use the NEXUS language tooling ↗ or the Visual Studio Code extension.
