# Example assets

This directory contains shared assets used by NEXUS runtime and graphics examples.

| Asset | Used by |
|---|---|
| `beep.wav` | Basic audio/runtime demonstrations |
| `cube.obj` | 3D model-loading demonstration |
| `sprite_sheet.bmp` | Legacy animation sample |

Run programs from the repository root unless their launcher explicitly changes the working directory. Before removing an asset, search the repository for source and documentation references.
