Скопируй весь текст ниже в другого агента (Codex / Claude Code / Cursor / другой ИИ).

## Роль

Ты — senior game developer и инженер графического рантайма. Твоя задача — довести существующую игру **NEXUS Poker** до состояния «релиз для игрока»: красиво, быстро, без ложных заглушек, с проверенным геймплеем. Ты работаешь в репозитории **NEXUS** и обязан сохранить сборку, тесты и стиль проекта.

Репозиторий: <https://github.com/fanxcz/nexus-lang> (ветка `main`).  
Игра: `examples/poker_gui.nx` — один файл на ~2 300 строк.  
Снимок на момент передачи: `handoff/poker_gui.nx` (идентичен `examples/poker_gui.nx` версии 2.1.0).

## Что уже работает (не сломай)

- Главное меню: выбор 1–5 ботов, стартовый стек 1 000, блайнды 10/20, кнопка `START TABLE`, `F11` — фуллскрин, `Esc` — выход.
- Настоящий No-Limit Texas Hold'em: префлоп, флоп, тёрн, ривер, `FOLD` / `CHECK` / `CALL` / `RAISE` со слайдером / `ALL-IN`, showdown, side pots, split pots, оценка лучшей пятёрки из семи карт.
- 6-макс. гексагональная посадка, человек снизу, боты рассаживаются симметрично.
- ИИ ботов: сила руки, пот-оддсы, агрессия по месту, рейзы/фолды/олл-ины.
- TTF-типографика через `gfx_font_default`, `gfx_text_font`, `gfx_text_width/height`, `gfx_font_style`; запасной bitmap-шрифт.
- Логический холст 1920×1080, окно 1600×900, апскейл/леттербокс; предрендеренный стол `examples/assets/table/felt.png`.
- Арт: 52 карты + рубашка (`examples/assets/cards/`), кастомный курсор-стрелка (`examples/assets/ui/cursor.png`), звуки (`examples/assets/sounds/`).
- Стек, банк, фишки по номиналам, аватары, таблички, D/ SB/ BB, статусы действий, анимация раздачи, быстрый темп (~0.24–0.5 c на бота, 6 c на авто-следующую руку).
- Курсор ОС скрыт, рисуется свой PNG с хотспотом на острие; DPI-aware (`SDL_WINDOWS_DPI_AWARENESS=permonitorv2`).
- Банкролл сохраняется в `poker_save.txt`; экраны `YOU'RE OUT`, `PLAY AGAIN`, `MAIN MENU`, `TABLE WON`.
- Проверено: `nexus check examples/poker_gui.nx`, сборка LLVM, `ctest` 36/36, `mkdocs build --strict`, FPS ~50–55 на software-рендерере.

## Известные ограничения и баги — приоритеты

1. **Разрешение и окно.** Сейчас окно 1600×900, логика 1920×1080. Добавь настройку/параметр запуска для настоящего 1920×1080 и запоминание размера окна; проверь, что координаты мыши и хитбоксы не расходятся на 125/150 % DPI.
2. **Нижняя панель.** Кнопки `FOLD`/`CALL`/`ALL-IN`/`RAISE`, подпись `RAISE TO`, слайдер и подписи min/max стоят вплотную к нижнему краю. Сделай адаптивную раскладку без наложений на 16:9 и 16:10, при 1280×720 и 1920×1080.
3. **Анимации.** Раздача есть, но нет переворота карт, полёта фишек в банк, выплаты банка, подсветки пяти лучших карт. Добавь короткие (150–350 мс) анимации, не замедляя темп.
4. **Боты.** Эвристика. Добавь позицию (UTG/CO/BTN/SB/BB), пот-оддсы, вероятность блефа, индивидуальные характеры (тайт/лузовый), Monte-Carlo эквити (без подвисаний) и запрет «видеть» будущие карты доски.
5. **Side pots.** Логика есть, но визуально банк один. Покажи основной банк и сайд-поты отдельными суммами и списком игроков, имеющих право на каждый.
6. **Showdown.** Показывай категорию комбинации у всех вскрытых игроков, подсвечивай 5 карт лучшей комбинации, упорядочь вскрытие. Сейчас строка выплаты агрегируется — проверь, что при нескольких победителях суммы и имена читаются однозначно.
7. **Пустые/выбывшие места.** Проверь, что бот с 0 фишек не получает карты, не участвует в блайндах и не рисуется как активный; проверь переход «остался один».
8. **Хедз-ап.** При 2 игроках (1 бот) дилер — малый блайнд и действует первым на префлопе. Текущая раскладка мест рассчитана на 6-max — проверь и исправь.
9. **All-in меньше колла / меньше мин-рейза.** Проверь возврат невызванного остатка, корректность уровней сайд-потов и «неполного» рейза.
10. **Дробление нечётной фишки.** Сейчас остаток отдаётся первому по индексу места. Сделай по правилам: первому игроку слева от дилера среди победителей.
11. **Банкролл.** Проверь, не сбрасывается ли стек слишком агрессивно (`bankroll < 100` → 1000), и сохраняй банкролл отдельно для каждого числа ботов, если это уместно.
12. **Звук.** Добавь громкость/mute, не проигрывай звук при `Esc`, синхронизируй `deal.wav` с анимацией.
13. **Производительность.** 50–55 FPS на software-рендерере. Кэшируй повторяющиеся круги фишек, уменьшай овердро, проверь, что при 1920×1080 не падает ниже 60 FPS на целевом железе. Не ломай fallback.
14. **Локализация.** Добавь переключатель RU/EN для меню, статусов и экранов победы/проигрыша.
15. **Тесты.** Игровые чистые функции (`score_hand`, `best_of_board`, `best_of_seven`, side-pot разбиение) вынеси в тестируемый модуль/CLI-режим и покрой краевыми случаями: флеш на 5 картах, стрит A-2-3-4-5, каре, кикеры, split pot, 3 сайд-пота, пустой банк.

## Карта кода (ищи по именам)

- `Player` — структура игрока; `pay`, `build_players`, `new_player`, `total_committed`, `live_count`, `nonfolded_count`, `actionable_count`, `next_actionable`, `round_done`.
- Оценка рук: `score_hand`, `sort5`, `best_of_board` (только реально выданные карты доски), `best_of_seven` (showdown), `cat_name`, `preflop_strength`, `postflop_strength`.
- ИИ: `ai_action`, `ai_raise_to`.
- Отрисовка: `draw_menu`, `draw_cursor`, `draw_card`, `draw_pile`, `draw_pot`, `panel`, `paint_button`, `text_at/text_c/text_r`, `money`.
- Главный цикл: `main()`; меню — `screen == 0`, стол — иначе; фазы `phase` 0/1/2; `street` 0–4; `board_count`.
- Ассеты: `asset_path(rel)` проверяет `rel`, затем `examples/rel`; вызывай из корня репозитория или из `examples/`.
- Геометрия: `sx/sy` (аватары), `cx/cy` (карманные карты), `bx/by` (ставки).

## Сборка и запуск

```powershell
cd C:\nexus-lang-main
$env:NEXUS_CXX="C:\Program Files\LLVM\bin\clang++.exe"
$env:PATH="C:\Program Files\LLVM\bin;" + $env:PATH
.\build\nexus.exe check examples\poker_gui.nx
.\build\nexus.exe build examples\poker_gui.nx
$env:PATH="C:\Users\<user>\AppData\Local\Programs\NEXUS\runtime;" + $env:PATH
.\poker_gui.exe
```

Пересобрать компилятор и прогнать тесты:

```powershell
cmake --build build
ctest --test-dir build --output-on-failure
mkdocs build --strict -f .github/project-tools/repository-files/mkdocs.yml
```

Перегенерировать арт:

```powershell
python examples/assets/generate_assets.py
```

## Жёсткие требования

- Только мышь как основной ввод; клавиатура — необязательный fallback.
- Не менее 3 ботов, меню выбора количества, главное меню, фулл-HD канвас, кастомный курсор-стрелка.
- TTF-шрифты, не bitmap по умолчанию.
- Честная игра: боты не видят закрытые карты и будущие карты доски.
- Никаких фейковых заглушек, «TODO» вместо логики и отключённых тестов.
- Не делать force push, не переписывать историю, не ломать чужие изменения.
- Все изменения проверить сборкой и скриншотами; в отчёте честно перечислить, что осталось.

## Критерии готовности

1. Партия проходится мышью от меню до победы/проигрыша без клавиатуры.
2. 3–5 ботов играют корректно; видны блайнды, дилер, банк, ставки, очереди, вскрытие.
3. Side pot и split pot корректны настолько, что суммы сходятся с фишками за столом.
4. `nexus check`, сборка, `ctest` и `mkdocs --strict` зелёные.
5. FPS не ниже 55 на целевом ПК; окно/фуллскрин и курсор работают на DPI 100/125/150 %.
6. README/`docs/examples/games.md` описывают реальные controls и ограничения.
7. Изменения закоммичены и запушены в `origin/main` (без force push).
