# Game Examples

Complete games and game frameworks.

## Neon Survivor

`examples/neon_survivor.nx` — Twin-stick survivor game.

**Features:**
- Wave-based enemies
- Particle effects
- Score/wave system
- Health bar
- Pause menu
- Game over screen
- Sound effects

**Run:**
```bash
nexus run --example neon_survivor
```

## Nexus Arena

`examples/nexus_arena.nx` — Multiplayer-ready arena shooter.

**Features:**
- Multiple players (local)
- Projectile physics
- Power-ups
- Map system
- Score tracking

## Nexus Paint

`examples/nexus_paint.nx` — Full raster editor.

**Features:**
- 1024x720 canvas
- 6 tools (pencil, eraser, line, rect, fill, spray)
- 16-color palette
- Brush size 1-50
- Undo/redo history
- BMP save/load

## Terminal Game

`examples/terminal_game.nx` — Text-based game.

**Features:**
- Pure text rendering
- Turn-based combat
- ASCII graphics
- Inventory system

## Nexus Editor

`examples/nexus_editor.nx` — Code editor.
