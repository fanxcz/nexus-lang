# Screenshots

Place screenshot images here for the documentation site.

## Naming Convention

- `nexus_paint.png` — Nexus Paint application
- `neon_survivor.png` — Neon Survivor game
- `3d_demo.png` — 3D graphics demo
- `editor.png` — Code editor
- `terminal_game.png` — Terminal game
- `showcase.png` — Ultimate showcase

## Format

- PNG format recommended
- Max width: 1280px
- Max file size: 500KB per image
- Use dark theme to match documentation
