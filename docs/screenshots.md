# Screenshots and demos

The current source archive does not contain verified application screenshots. Rather than display broken or misleading images, this page records the visual demos available in the repository.

## Included demos

- **Nexus Paint** — raster canvas example with drawing tools.
- **Neon Survivor** — wave-based survival game example.
- **Nexus Arena** — arena-style game example.
- **3D demo** — native 3D rendering example.
- **Terminal game** — text-based game example.

Open the source files in the [`examples/` directory](https://github.com/fanxcz/nexus/tree/main/examples). Screenshots will be linked here after captures from real runs are added to the repository.
