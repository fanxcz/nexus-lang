# Package Manager Overview

NEXUS includes a built-in package manager for local package vendoring with lockfile support.

## Features

- **Local packages only** (v1.1.0) — packages vendored into `vendor/`
- **Lockfile** — `nexus.lock` ensures reproducible builds
- **No central registry** — decentralized, Git-based workflow (registry planned)
- **Version constraints** — SemVer compatible
- **Transitive dependencies** — automatic resolution

## Quick Start

```bash
# Create a library package
nexus new my-lib --template library
cd my-lib
# ... develop library ...

# In your application
cd ../my-app
nexus pkg add ../my-lib
nexus pkg build
nexus build
```

## Package Structure

```
my-lib/
├── nexus.toml          # Package manifest
├── src/
│   ├── lib.nx          # Library entry point
│   └── *.nx            # Modules
├── tests/              # Package tests
├── examples/           # Usage examples
└── README.md
```

## Creating a Package

### 1. Initialize

```bash
nexus new my-math --template library
cd my-math
```

### 2. Configure `nexus.toml`

```toml
[package]
name = "my-math"
version = "1.0.0"
edition = "2026"
description = "Math utilities for NEXUS"
license = "MIT"
repository = "https://github.com/you/my-math"

[build]
entry = "src/lib.nx"

# Optional: export specific modules
[lib]
path = "src/lib.nx"
```

### 3. Write Library Code (`src/lib.nx`)

```nx
module my_math {
    export const PI: f64 = 3.14159265359
    
    export fn sin(x: f64) -> f64 { ... }
    export fn cos(x: f64) -> f64 { ... }
    export fn sqrt(x: f64) -> f64 { ... }
    
    export struct Vec2 {
        x: f32,
        y: f32,
    }
    
    export impl Vec2 {
        fn new(x: f32, y: f32) -> Self { ... }
        fn length(&self) -> f32 { ... }
        fn normalize(&self) -> Self { ... }
    }
}
```

### 4. Build and Test

```bash
nexus build          # Build library
nexus test           # Run package tests
nexus doc            # Generate docs
```

## Using Packages

### Add Local Package

```bash
# Add from relative path
nexus pkg add ../my-math

# Add from absolute path
nexus pkg add /path/to/my-math

# Add from Git (future)
# nexus pkg add https://github.com/user/my-math --rev v1.0.0
```

This creates/updates:
- `vendor/my-math/` — vendored copy
- `nexus.lock` — lockfile with exact versions

### Import in Code

```nx
// main.nx
import my_math

fn main() {
    let v = my_math.Vec2::new(3.0, 4.0)
    println("Length: {}", v.length())  // 5.0
}
```

### Build with Dependencies

```bash
# Builds all dependencies first
nexus build

# Or explicitly
nexus pkg build
nexus build
```

## Lockfile (`nexus.lock`)

```toml
# Generated by nexus pkg add/update
# Do not edit manually

[package.my-math]
version = "1.0.0"
source = { path = "../my-math" }
checksum = "sha256:abc123..."
dependencies = []
```

Commit `nexus.lock` to version control for reproducible builds.

## Commands

| Command | Description |
|---------|-------------|
| `nexus pkg init` | Initialize package in current dir |
| `nexus pkg add <path>` | Add local package |
| `nexus pkg remove <name>` | Remove package |
| `nexus pkg list` | List installed packages |
| `nexus pkg update` | Update all packages |
| `nexus pkg build` | Build all packages |
| `nexus pkg publish` | Publish to registry (future) |

## Dependency Resolution

1. Read `nexus.toml` `[dependencies]`
2. Read `nexus.lock` for pinned versions
3. Vendor packages into `vendor/`
4. Build dependency graph
5. Compile in topological order

## Versioning

Follows [Semantic Versioning](https://semver.org/):

```toml
[dependencies]
my-lib = "1.2.3"        # Exact version
my-lib = "^1.2.3"       # Compatible (>=1.2.3 <2.0.0)
my-lib = "~1.2.3"       # Patch only (>=1.2.3 <1.3.0)
my-lib = ">=1.0.0"      # Range
my-lib = "*"            # Any version
```

## Best Practices

1. **Commit `nexus.lock`** — ensures reproducible builds
2. **Vendor dependencies** — `vendor/` should be in `.gitignore` but lockfile committed
3. **Semantic versioning** — bump versions correctly
4. **Minimal dependencies** — prefer stdlib when possible
5. **Test packages** — run `nexus test` before publishing

## Troubleshooting

### Package not found
```bash
# Ensure package is added
nexus pkg list

# Re-add if missing
nexus pkg add ../my-lib
```

### Version conflict
```bash
# Check lockfile
cat nexus.lock

# Update to compatible versions
nexus pkg update
```

### Build fails
```bash
# Clean and rebuild
nexus clean --all
nexus pkg build
nexus build
```
